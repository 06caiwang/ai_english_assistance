> 什么时候需要看这份文档：**换电脑、换数据库密码、换 API Key、上真机、交作业之前。**
> 平时在自己电脑上开发，只需要一个 `MYSQL_PASSWORD` 环境变量，其余都不用动。

## 一、全部需要动的配置（6 处）

| # | 文件 | 配置项 | 当前状态 | 说明 |
|---|---|---|---|---|
| 1 | `python-ai/.env` | `DEEPSEEK_API_KEY` 等 4 项 | **文件不存在**，靠系统环境变量 | 换机器时必须建；本机已有系统变量，可暂时不建 |
| 2 | `spring-server/src/main/resources/application.yml` | `password: ${MYSQL_PASSWORD:}` | 已改为环境变量注入 | 启动前必须 `export MYSQL_PASSWORD=...`，否则连不上库 |
| 3 | 同上 | `app.jwt.secret` | 固定的开发默认值 | **改了它 = 所有设备当前登录态立刻失效**，App 会提示"登录已过期"并要求重新登录（不是 bug） |
| 4 | `android-app/app/build.gradle.kts` | `BASE_URL` | 默认 `http://10.110.4.238:8080/`（当前局域网 IP） | 模拟器用 `-PbaseUrl=http://10.0.2.2:8080/` 覆盖，不用改文件 |
| 5 | `android-app/app/src/main/res/xml/network_security_config.xml` | 允许明文 HTTP 的域名 | 只有模拟器地址 | 真机 IP 要加进来，否则请求一直转圈 |
| 6 | `android-app/local.properties` | `sdk.dir` | 本机 SDK 路径 | 换机器后由 Android Studio 自动重写，**不要提交** |

## 二、分场景：你只要改其中的几项

### 场景 A：就在这台电脑继续开发（最常见的状态）

```bash
export MYSQL_PASSWORD='你的 MySQL root 密码'   # 每次开新终端都要设
```
其余 5 项都不用动。当前系统环境里已经有 `DEEPSEEK_API_KEY`，AI 功能直接可用。

### 场景 B：换一台电脑

| 步骤 | 操作 |
|---|---|
| 1 | 装 JDK 17、MySQL 8、Android Studio、Python 3.12+ |
| 2 | 导入 `db/schema.sql` + `db/seed.sql` + `db/patch_food.sql` |
| 3 | 建 `python-ai/.env`（从 `.env.example` 复制），填 `DEEPSEEK_API_KEY` |
| 4 | 重建 venv：`cd python-ai && python -m venv .venv && .venv/Scripts/python.exe -m pip install -r requirements.txt` |
| 5 | 用 Android Studio 打开 `android-app/`，让它重写 `local.properties` 的 `sdk.dir` |
| 6 | `export MYSQL_PASSWORD=...` 后再启动后端 |

### 场景 C：插真机演示

`BASE_URL` 已经支持命令行覆盖，**不用改文件**：

```bash
cd android-app
./gradlew installDebug                                          # 用默认（当前局域网 IP）
./gradlew installDebug -PbaseUrl=http://10.0.2.2:8080/          # 模拟器
./gradlew installDebug -PbaseUrl=http://192.168.1.100:8080/     # 换一个手机热点
```


| 改哪里 | 改成什么 |
|---|---|
| `android-app/app/build.gradle.kts` 的 `BASE_URL` | `"http://192.168.x.x:8080/"`（电脑局域网 IP，`ipconfig` 查） |
| `network_security_config.xml` | 加一行 `<domain includeSubdomains="true">192.168.x.x</domain>` |
| 手机与电脑 | 连同一个 WiFi；电脑防火墙放行 8080 |
| 后端启动参数 | `--server.address=0.0.0.0`（默认已是），不要只绑 127.0.0.1 |

## 三、API Key 从哪来、怎么填

1. 去 DeepSeek 开放平台（`platform.deepseek.com`）→ API Keys → 新建
2. 复制 `sk-` 开头的串
3. 在 `python-ai/` 下把 `.env.example` 复制成 `.env`，填进去：

```ini
DEEPSEEK_API_KEY=sk-你的key
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
LLM_MODE=
```

> `LLM_MODE` 留空会自动判断：有 Key 走真模型，没 Key 走 Mock。
> **没有 Key 项目照样能跑**（翻译/打分/生成都返回结构合法的假数据），答辩演示风险更低。
> 想强制演示 Mock：`LLM_MODE=mock`。

**注意**：`.env` 已在 `.gitignore` 里，不要把它发给别人；如果要交源码，交 `.env.example`。

## 七、踩过的坑：一次真实的 401 排查

现象：App 一直弹 401，登录页和首页来回跳。

| 环节 | 原因 | 修法 |
|---|---|---|
| 服务端 | `app.jwt.secret` 被改成了新的随机串，旧 token 签名对不上，但**时间还没过期**，所以报的是"登录已过期"而不是解析异常 | 密钥固定成稳定值，改之前要知道后果 |
| 登录页 | 只要本地有 token 就跳首页，失效 token 造成 401 → 回登录 → 又自动跳 → 死循环 | 改为先调 `/api/user/me` 校验，通过才跳 |
| 退出逻辑 | `logout()` 在协程（后台线程）里直接 `startActivity`，可能静默失败，表现为"401 了却停在原页面" | 切到主线程执行，并把清 token 改成同步 `commit()` |

判断方法（以后遇到 401 先做这个）：
1. 把设备里的 token 拿出来解码，看 `iat/exp`：没过期就不是时间问题；
2. 用同一个 token 直接 curl 后端：报"登录已过期"=签名/密钥不匹配；报"未登录"=请求没带 header；
3. 重新登录拿到新 token，如果新 token 能用，就是密钥被改过。

## 八、第二次排查：AI 作文报错 + 局域网 IP 变了

现象：接口冒烟 23/25，翻译正常，**作文打分和作文生成报「AI 服务暂时不可用」**；App 上则表现为请求发出去没反应。

### 问题 1：后端等 AI 只等 10 秒，作文要 24 秒

| 项 | 值 |
|---|---|
| 现象 | `/api/ai/translate` 正常（1 次模型调用，约 1 秒）；`/api/ai/essay` 必失败（5 次调用，实测 **24 秒**） |
| 真因 | `RestTemplateConfig` 里 `setReadTimeout(10_000)` |
| 为什么以前能过 | 模型延迟有波动，之前几次刚好压在 10 秒内，属于"擦边通过" |
| 修法 | `setReadTimeout(120_000)`、`setConnectTimeout(5_000)` |

> 这是最容易误判的坑：**翻译能用 → 说明 AI 服务没挂 → 于是怀疑 Key 或 prompt**。
> 实际只是"单次调用能过、多次调用超时"。以后看到"部分 AI 功能失败"，先量一下耗时。

### 问题 2：BASE_URL 指向的局域网 IP 已经失效

| 项 | 值 |
|---|---|
| 旧值 | `http://10.110.4.238:8080/`（前一天的真机调试地址） |
| 现在 | 本机 WLAN 是 `10.210.125.29`，旧 IP 已不可达 |
| 后果 | App 请求发到不存在的地址，表现为连不上/一直转圈，和"后端挂了"极像 |
| 修法 | 默认值改成当前 IP；`network_security_config` 放开明文（局域网 IP 会随 DHCP 变，逐条加白名单不现实） |

**以后 IP 再变，不用改文件**：

```bash
cd android-app
./gradlew installDebug -PbaseUrl=http://$(ipconfig | grep -A1 WLAN | grep IPv4 | awk '{print $NF}'):8080/
# 或直接写死
./gradlew installDebug -PbaseUrl=http://192.168.1.100:8080/
```

### 顺带发现：`python-ai/.env` 的三处写法

| 项 | 原值 | 现值 | 说明 |
|---|---|---|---|
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | `https://api.deepseek.com/v1` | 官方推荐带 `/v1` |
| `DEEPSEEK_MODEL` | `deepseek-flash` | `deepseek-chat` | 换完**作文批改从 24s 降到 8.5s** |
| `LLM_MODE` | `deepseek`（写死） | 留空 | 有 Key 走真模型，无 Key/断网自动降级 Mock，演示更稳 |

> 已修改并实测通过（翻译/批改/生成三个接口均为真实模型返回）。
